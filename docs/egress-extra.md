# エグレス削減の追加修正

前の `supabase-egress-reduction.patch` を適用したコードに対する追加パッチです。SQL変更は不要です。GitHubへのpush・本番デプロイはこの作業では行っていません。

## 変更

- R2投稿写真が既存の端末キャッシュにあれば、表示用の署名URLを再発行しない。キャッシュが確認後に消えた場合は画像コンポーネントから署名URLを取得する。
- キャッシュ未保存の画像は署名URLを有効期限内で共用し、重複する同時発行もまとめる。原本・サムネイルとオブジェクトキーを区別する。写真ダウンロード操作は従来どおり認証して原本を取得する。
- ストリームの新着IDを150ms単位でまとめ、最大150件ずつDB取得する。表示順・メンション・ハート情報・画像サイズは維持する。
- 非表示中は新着IDを保持し、ストリームの新規DB取得と全体再取得を保留。表示に戻ると取得する。Realtime購読は維持するため、Realtime配信バイト自体は減らない。既に開始したリクエストは止めない。
- 通知はRealtimeの完全な行情報を使って追加・既読更新・削除する。最新50件、並び順、未読数を維持する。不完全なイベントでは従来のDB再取得を行う。DB取得中に届いた通知は結果に反映し、古い取得結果が新しい結果を上書きしない。
- Cache Storageが使えない/保存できない場合も通常の画像表示にフォールバックする。

ランキングの更新周期、ポイント付与、投稿/削除/編集、公開範囲、RLS、画像圧縮率、DB関数は変更していません。新着投稿の追加は最大150msのまとめ待ちを追加しています。非表示中のハート再取得フォールバックや画像取得など全通信を止めるものではありません。

## 適用

Windowsのプロジェクトディレクトリで、Downloadsへ保存したパッチを適用します。

```bat
git apply ..\egress-extra.patch
npm run typecheck
```

前の削減パッチが未適用なら、先に `git apply ..\supabase-egress-reduction.patch` を実行してください。適用後は通常どおりコミット・pushしてVercelに反映します。
